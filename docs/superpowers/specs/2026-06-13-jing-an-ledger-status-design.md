# 《谍影迷梦》静安书局账页状态栏设计

## 目标

将当前状态栏重塑为“静安书局内部借阅账页”：它表面上是一页旧书局账册，实际承载地下情报人员的行动记录。设计需要提升材质、字体和信息层级，同时保持长期阅读舒适，避免再次落入泛用的奶油色复古卡片或现代游戏 HUD。

本次仅调整状态栏前端表现与只读交互，不修改角色卡正文、世界书、变量结构、变量值、状态栏条目或人物资料。

## 设计方向

采用视觉样稿 A“书局借阅账页”。整体克制，不使用大面积 `TOP SECRET`、电报夹页、夸张印章或繁复装饰。

主题依据来自角色卡中的静安书局地下联络点、旧木招牌、书页和借阅记录。时代参考以民国时期书衣和内页装帧的素雅、内敛、多样性为原则，而不是套用现代西式档案模板。

## 视觉系统

### 色彩

- 账页纸 `#EEE4CF`：主要内容底色。
- 纸面高光 `#F7F0DF`：局部提亮和已展开档案。
- 书局蓝灰 `#40505A`：页眉与主要结构色，呼应沈静姝的蓝色布旗袍和静安书局的安静气质。
- 暖墨 `#282722`：正文主色。
- 褪色墨 `#746C5F`：辅助文字与锁定状态。
- 暗批红 `#8F3030`：代号、主线和高优先级标识。
- 旧黄铜 `#A98B50`：边线、页码与轻度强调。
- 褪色翡翠 `#416756`：观察等安全向状态。

所有颜色收敛为 CSS 变量。警觉度、技能条和好感度沿用既有语义映射，不增加新的状态类别。

### 字体

- 中文正文：`Microsoft YaHei UI`, `Microsoft YaHei`, `PingFang SC`, sans-serif。
- 中文标题与人物姓名：优先 `YouYuan`，回退到正文无衬线字体；字重 700，不使用细宋体。
- 时间、页码和数字：`Cascadia Mono`, `Consolas`, monospace。

等宽字体仅用于数字和短编号，不承担中文地点、任务或正文，避免中文笔画生硬。

### 材质与标志性元素

- 纸张质感仅由低对比度渐变、细横纹和内阴影组成，不依赖图片或外部资源。
- 外框采用薄边线与轻微书页阴影，圆角控制在 2–4px。
- 标志性元素是右下角的小型“静安书局藏书”藏书印记。
- 分区使用真实账页语义：`FOLIO 01`、`FOLIO 02`，分别对应特工状态和人物档案。
- 不增加虚构组织编号、密级或英文口号。

## 布局

状态栏保持最大宽度 720px，并支持约 360px 的窄屏环境。

```text
┌────────────────────────────────────┐
│ 静安书局 · 内部借阅簿       警觉度 │
│ 地点                        日期时间 │
├────────────────────────────────────┤
│ 特工状态                 FOLIO 01   │
│ 枪械 ━━━ 15   潜行 ━━━ 20          │
│ 交际 ━━━ 35   观察 ━━━ 30          │
│ 金钱 / 青帮 / 巡捕房                │
├────────────────────────────────────┤
│ 人物档案                 FOLIO 02   │
│ 已相识人物展开档案                  │
│ 未相识人物紧凑网格                  │
├────────────────────────────────────┤
│ 主线 任务名称 / 剩余时间             │
│                         静安书局藏书 │
└────────────────────────────────────┘
```

- 481px 以上技能和人物卡使用两列或自适应多列。
- 480px 以下技能改为单列；未相识人物仍尽量保留双列，只有极窄空间才变为单列。
- 长地点、人物姓名和任务允许换行或省略，不产生横向滚动。
- 展开人物独占整行；锁定人物不能进入展开状态。

## 组件设计

### `App.vue`

负责账页外框、纸面渐变、轻微内阴影和藏书印记。保留当前四个子组件及其顺序，不增加新的业务层。

### `SystemHeader.vue`

使用蓝灰书封式页眉。显示现有时间、地点和警觉度，内容原样绑定 `store.data.系统`。标题“静安书局 · 内部借阅簿”属于前端装帧标识，不取代任何状态条目。

### `PlayerPanel.vue`

保留枪械、潜行、交际、观察、金钱、青帮声望、巡捕房声望及 `/100` 格式。技能条提高对比度，但不使用强发光、厚渐变或动态扫光。

### `CharacterRoster.vue`

- 点击已相识人物卡片展开或收起详情。
- 点击未相识人物不改变展开状态。
- 五个身体部位使用 `<button type="button">`。
- 使用 `@click.stop`，部位点击不能触发人物卡片收起。
- 以“人物 key + 部位 key”记录当前选择，避免人物间串状态。
- 详情只显示已有的部位名称和状态值，不生成解释性描述，不修改 MVU 数据。
- 按钮具备 hover、active、focus-visible、selected 和 `aria-pressed` 状态。
- 纯洁与经验使用文字、颜色和标记共同区分，不能只依赖 emoji。

### `QuestPanel.vue`

保留“任务与委托”“主线”、完整任务原文和“剩余 X 小时”格式。视觉表现为账页中的暗红批注，不改成英文标签。

## 数据边界

- 所有变量继续读取 `store.data`。
- 不修改 `schema.ts`、`store.ts` 或 `index.ts` 的业务行为。
- 不重命名任何中文 key。
- 不通过点击写入变量。
- 不新增外部字体、图片、网络请求或 npm 依赖。
- 角色卡的文本状态块重复问题通过展示层处理，不改写角色原文；该修复与视觉组件保持独立。

## 动效与可访问性

- 技能条和好感度条仅保留短时宽度过渡。
- 卡片展开、按钮选择使用 150–220ms 的透明度和颜色变化，不使用弹跳或大幅位移。
- `prefers-reduced-motion: reduce` 时关闭非必要过渡。
- 键盘焦点必须可见；正文和辅助文字应维持可辨识对比度。

## 错误处理

- 数据由 schema 默认值保护；组件不得自行创造缺省业务值。
- 身体状态读取时只接受 schema 中的 `纯洁` 和 `经验`。
- 选中人物被收起后保留其部位选择，下次展开恢复；切换到其他人物时不会复用该选择。
- 锁定人物即使被点击也不展开、不改变当前已展开人物。

## 测试与验收

### 自动化测试

- 保持现有 `store.data` 契约测试。
- 保持八名人物的数据绑定测试。
- 新增身体部位按钮语义、`@click.stop`、只读状态和按人物隔离选择的测试。
- 新增锁定人物不可展开的测试。
- 新增状态条目文案保护测试，防止资源、任务和 `/100` 格式被视觉重构改写。
- 生产构建必须成功。

### 浏览器验收

- 720px：信息紧凑但不拥挤，人物网格平衡，纸张质感清晰而克制。
- 360px：无横向滚动，地点和任务正常换行，身体部位按钮可点击。
- 已相识人物可展开；部位点击后人物不收起，详情显示正确。
- 未相识人物点击无布局变化。
- 浏览器控制台无错误。
